# Тестовое задание: Обработка заказов (PHP)

Консольный скрипт для парсинга, валидации и анализа списка заказов в формате JSON.

## Стек и требования
* PHP 8.1+
* CLI (командная строка)
* Без сторонних библиотек

## Функционал
1. **Парсинг и валидация данных:**
   * Проверка корректности JSON.
   * Контроль наличия обязательных полей (`id`, `customer`, `amount`, `status`).
   * Проверка суммы заказа (`numeric`, `>= 0`).
   * Проверка допустимых статусов по белому списку (`paid`, `pending`, `canceled`).
2. **Аналитика оплаченных заказов:**
   * Фильтрация заказов со статусом `paid`.
   * Подсчёт общего количества и суммы оплаченных заказов.
   * Поиск самого дорогого заказа.
3. **Дополнительно (Вариант Б):**
   * Группировка всех валидных заказов по статусам с подсчётом количества.
